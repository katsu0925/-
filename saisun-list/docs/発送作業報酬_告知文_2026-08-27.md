# 発送作業報酬ルール 再告知（2026-08-27）

外注の発送担当者へ送る文面。メール／チャットのどちらでもそのまま貼り付けて使える。

## 1. メール用（そのまま送れる本文）

**件名:** 【重要】発送作業の報酬ルール変更のお知らせ（8月27日から）

いつも発送作業をありがとうございます。
2026年8月27日から、発送作業の報酬の計算方法を変更しますのでお知らせします。

### 何が変わるか

| | 計算方法 |
|---|---|
| これまで | 1回の発送につき、箱のサイズごとの金額 |
| これから | 箱のサイズごとの金額 × 発送した箱の数 |

これまでは、1回の依頼を複数の箱に分けて発送しても1箱分しかお支払いできていませんでした。
今後は発送した箱の数だけお支払いします。

### 報酬表（1箱あたり）

| 発送サイズ | 報酬 |
|---|---|
| クリックポスト | 50円 |
| 中箱 | 100円 |
| 大箱 | 250円 |
| 大箱（日本郵便で発送したとき） | 350円 |

- クリックポストは、日本郵便で発送しても50円です。
- 大箱を日本郵便で発送したときの350円は以前からのルールですが、報酬表に載っていなかったため、あらためてお知らせします。

### 計算例

- 大箱を3箱 → 250円 × 3箱 = **750円**
- 大箱を1箱、日本郵便 → **350円**
- 中箱を2箱 → 100円 × 2箱 = **200円**
- クリックポストを1通 → **50円**

### お願い（ここがいちばん大事です）

発送が終わったら、依頼管理シートの次の2つを必ず入力してください。伝票番号のすぐ右にあります。

1. **発送サイズ**（V列）… プルダウンから「クリックポスト」「中箱」「大箱」を選ぶ
2. **箱数**（W列）… 発送した箱の数を数字で入れる

- **発送サイズが空欄だと、報酬が計算されません**（金額が入らないままになります）。必ず選んでください。
- 箱数が空欄のときは1箱として計算します。2箱以上のときは必ず数字を入れてください。

### これまでの分について

8月26日以前にお受けした依頼の報酬は、そのままで変わりません。
ただし、7月25日以降にお受けした依頼で発送サイズと箱数の両方を入力していただいた分は、新しいルールで計算し直されます。入力もれがあった分は、入れていただければ反映されます。

ご不明な点がありましたらご連絡ください。
引き続きよろしくお願いいたします。

NKonline

## 2. チャット用（短縮版）

【報酬ルール変更のお知らせ・8月27日から】

発送報酬を「サイズごとの金額 × 箱数」に変更します。
複数の箱で発送したときに、これまで1箱分しかお支払いできていなかったのを直すものです。

1箱あたり
・クリックポスト 50円
・中箱 100円
・大箱 250円
・大箱（日本郵便）350円
※クリックポストは日本郵便でも50円です

例）大箱3箱＝750円／中箱2箱＝200円

【お願い】
発送が終わったら、依頼管理シートの「発送サイズ」（伝票番号の右どなり）と「箱数」を必ず入力してください。
・発送サイズが空欄だと報酬が計算されません
・箱数が空欄だと1箱として計算します

8月26日以前の分の報酬はそのままです。よろしくお願いします。

## 3. 社内メモ（外注さんには送らない）

- 発効日は 2026-08-27。依頼日時がこの日以降の行は無条件で新ルール（v3）。
- 2026-07-25〜2026-08-26 の行は旧ルール（v2）据え置き。ただし**発送サイズと箱数の両方**が入力されている行だけ新ルールで再計算される。
- 2026-07-24 以前の行は再計算の対象外。箱数を入れても金額は変わらない（確定・支払済みを遡って動かさないため）。
- 判定は行に焼かれたシート数式の中で行っている（`buildRewardFormulaV2WithBoxOverride_` / `Constants.gs`）。入力した瞬間に金額が変わる。
- **AG列（作業報酬）を手で書き換えないこと。** 毎朝4〜6時の自己修復で自動生成の数式に戻る。
- 数式をすぐ入れ直したいときは `repairIraiKanriMissingFields()`（`RequestSheetRepair.gs:232`）をGASエディタから実行する。
- 入力欄の位置：発送サイズ＝V列、箱数＝W列（`REQUEST_SHEET_COLS.SHIP_SIZE` / `BOX_COUNT`、`Constants.gs`）。プルダウンと入力規則は `Product.gs:152` 付近で付与している。
