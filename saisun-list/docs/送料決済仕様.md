## 概要

商品代に加え、送料を自動計算してKOMOJU決済に含める仕組み。
送料は**地域×5サイズ（60〜160）＋pt制箱詰め**で自動計算し、点数上限なし（超過分は複数口）。

**ダイヤモンド会員（累計50万円以上）は送料無料。**

## 1. 送料体系（2026-07改定）

### 1-1. 基本ルール

- **顧客送料 = 佐川急便 江坂発運賃表（実費）× 1.5、¥10単位切上げ、税込**
- 沖縄は現行2段階の読み替え: 60/80/100サイズ=2,500円、140/160サイズ=3,500円（**沖縄宛はゆうパックで発送**）
- 離島は配送対象外（`REMOTE_ISLANDS` で住所判定しブロック）
- 会員割引は送料には適用しない（商品代のみ）
- 最低購入点数: **1点**（デタウリ・アソートとも）

### 1-2. 厚み判定・pt制

| 分類 | 判定 | pt |
|---|---|---|
| 薄手 | `shippingMethod === 'ゆうパケットポスト'` | 1pt |
| 厚手 | それ以外（空含む） | 2pt |

### 1-3. 箱容量とDP箱詰め

| 箱サイズ | 収容pt |
|---|---|
| 60 | 2pt |
| 80 | 4pt |
| 100 | 10pt |
| 140 | 20pt |
| 160 | 40pt |

- 合計ptに対し**動的計画法（DP）で最安の箱組み合わせ**を算出。同額なら小さい箱を優先
- 160サイズ超過は複数口（例: 41pt → 160＋60の2口）。**点数上限・後決済フォールバックは廃止**
- 実装: `Config.gs calcBoxPlan_` / `CartCalc.html calcBoxPlan` / `workers submit.js calcBoxPlan`（3実装同一ロジック）
- 設定値は `Constants.gs SHIPPING_CONSTANTS`（ITEM_POINTS / BOX_CAPACITY / BOX_SIZES）に集約

### 1-4. クリックポスト（全国一律¥280）

- 適用条件: **カート内のデタウリが薄手ちょうど1点**のとき（アソート併売でも適用）
- 全国一律・**沖縄含む**・住所入力前でも確定表示可
- 実費185円 ※**2026-10-01に240円へ改定**（日本郵便公式告知済）→ `Constants.gs CLICKPOST_COST` / `workers submit.js CLICKPOST_COST` を改定日に更新

### 1-5. 送料無料の優先順位

```
1. ダイヤモンド会員（累計50万円以上）→ 全地域無料
2. クーポン送料無料
3. 商品合計1万円以上 → 無料（FHP・価格破壊商品(BLK-H2LZTP36)・沖縄県は対象外）
4. クリックポスト ¥280（薄手1点）
5. pt制箱詰めDP送料
```
※沖縄はクーポン送料無料・1万円以上無料の対象外 → クリックポスト¥280は適用される

## 2. 不正利用対策（2026-07追加）

- **0円注文防止**: ポイント利用上限 = 支払合計−1円のキャップを CartCalc / workers submit.js / SubmitFix.gs の3実装で同一適用。サーバー側は支払0円注文をエラーで拒否（バックストップ）
- **新規登録reCAPTCHA（v3）**: index.html / BulkLP.html の登録フォームでトークン取得 → Worker（`RECAPTCHA_SECRET`設定時）と GAS（`verifyRecaptcha_`、常時）で検証。score < 0.3 はbot判定で拒否

## 4. 送料計算の実装箇所

| レイヤー | ファイル | 内容 |
|---|---|---|
| フロント共通 | CartCalc.html（正本）/ CartCalc.js（手動ミラー） | `calcShipment(thick, thin, rates)`。クリポ判定→DP箱詰め。`normalizeRates` で旧2段階形状も吸収 |
| GAS | Config.gs | `SHIPPING_RATES` / `SHIPPING_ACTUAL_RATES` / `calcBoxPlan_` / `calcShippingByAddress_` / `calcStoreShippingByAddress_` |
| GAS | Constants.gs | `SHIPPING_CONSTANTS`（pt・箱容量・クリポ価格/実費・送料無料閾値） |
| GAS | SubmitFix.gs | 注文送信時の送料確定（顧客送料＋店負担実費） |
| Workers | src/handlers/submit.js | GAS SubmitFix.gs と同一ロジック。D1 `SHIPPING_CONFIG_V2` から動的読込（形状不正時はハードコードへfail-closed） |
| 同期 | SyncApi.gs `exportSettings_` | `SHIPPING_CONFIG_V2`（5サイズ表＋実費表＋pt設定＋クリポ）をD1へ5分同期。旧キー`SHIPPING_CONFIG`も移行ウィンドウ用に出力 |

※CartCalc.html を編集したら必ず `cd saisun-list && sed '1d;$d' CartCalc.html > CartCalc.js` でミラー同期すること。

### 送料分別ルール（BASE_注文同期時）

```
送料 > 0 → AD列(客負担) に設定
送料 = 0 → 実費表160サイズ × 口数 → AC列(店負担) に設定

点数計算ルール:
  確認リンク(I列)にデータあり → 1点として計算
  確認リンク(I列)空 → K列(合計点数)をそのまま使用

注文に複数商品がある場合:
  最初の新規行にのみ送料を設定（重複計上防止）
```

## 6. 会員ランク制度（実装済み）

| ランク | 年間購入金額 | ポイント還元 | 特典 |
|---|---|---|---|
| レギュラー | - | 1% | - |
| シルバー | 5万円〜 | 3% | - |
| ゴールド | 20万円〜 | 5% | - |
| ダイヤモンド | 50万円〜 | 5% | **送料無料** |

- 過去12ヶ月の完了注文金額で判定（年間ローリング更新）
- 救済: ダイヤ/ゴールド更新切れ後1ヶ月以内に5万円以上購入→前ランク復活
- 復帰ゴールド限定: 年間35万円でダイヤモンド昇格
