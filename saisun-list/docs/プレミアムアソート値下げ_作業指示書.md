### 0-2. 顧客価格 と 自動選定目標額 は別物（デカップル）

| | 定義 | 置き場所（実装後） |
|---|---|---|
| 顧客価格 | 客が払う金額 | シートD列 ＝ `BulkProduct.gs:50 PREMIUM_PRICE_V3_` が書き込む |
| 自動選定目標額 | 封入する個品のサイト価格合計の下限 | `SubmitFix.gs:1821 PREMIUM_ASSORT_TARGET_V3_`（旧= :1810 V2） |
| お得額 | 目標額 − 顧客価格 | **手打ちしない。`BulkProduct.gs` 内で差分から自動計算**してタイトル・説明に焼き込む |

**原則: この2つを同額にしない**（同額にすると「お得」訴求が消える）。

計算式: `1点単価 = (顧客価格 ÷ 目標額) × 平均サイト価格`

## 1. 改定内容（確定値）

### Step 1: 段階価格テーブルの歪み修正 ✅ 実装済

`コード.gs:1169` の1行のみ。

```
[199, 600]  →  [199, 700]
```

理由: 返品済み在庫880点の**95.6%が仕入値¥199以下**。倍率は 50→250=5.0倍 / 100→400=4.0倍 / 149→550=3.7倍 に対し **199→600 だけ3.0倍に急落**、249→750も3.0倍。¥150-199帯（195点=22%）が過小評価。
効果: デタウリ平均サイト価格 **¥470 → ¥492（+4.7%）**。
バックフィル不要: `コード.gs:437 convertRecoveryK_(rec.cost)` が syncFull_ の毎回実行で全行を仕入値から再計算するため、1分Cron `syncListingPublicCron` で自動反映。
