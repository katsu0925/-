# 多言語辞書（デタウリ / アソート）

対応言語: **ja（既定）/ en / zh-CN**。既定は常に日本語で、ブラウザ言語による自動切替はしない。

## 仕組み

- `saisun-list/i18n.js` … ランタイム。日本語の原文をキーに DOM のテキストノードを置換する。
  MutationObserver で後から生成された DOM（商品カード・チャットボット等）にも追従する。
- `saisun-list/i18n-en.js` / `i18n-zh-CN.js` … 自動生成の辞書。**直接編集しない**。
- 日本語のまま使う人には辞書を一切ロードしない（追加転送量ゼロ）。
- 切替は `?lang=en` / `?lang=zh-CN`＋localStorage。切替時は必ずリロードする（翻訳は片方向のため）。

## 辞書の直し方

1. `i18n-src/NN.tsv` を編集する。1行 = `日本語|||English|||简体中文`（区切りは `|||`）
   - 番号が大きいファイルが後勝ち。既存訳を上書きしたいときは末尾のファイルに追記する。
   - 改行は `\n` と書く（実際の改行は入れない）。
2. `python3 i18n-src/build.py` を実行して `i18n-en.js` / `i18n-zh-CN.js` を再生成する。
3. commit → push（Cloudflare Pages が自動デプロイ）。GASにも反映するなら `clasp push` + `clasp deploy -i`。

数値が埋め込まれる文言（`780円` `60サイズ` `残り3個` など）は完全一致では拾えないので、
`build.py` の `PATTERNS`（正規表現→置換）側に書く。

## 翻訳しないもの（意図的）

- 商品名・ブランド名・記事タイトル … シート由来のデータ。日本語のまま
- 住所（〒600-8846 …） … 日本国内の住所は日本語表記が正
- ブランド検索のかな索引（あ/か/さ…）、管理者モードのバッジ（`translate="no"`）
