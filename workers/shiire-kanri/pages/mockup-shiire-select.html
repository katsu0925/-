仕入れプルダウン UX 比較

3案のモックアップ（タップ操作可）

現状（ネイティブ select）参考

iOS 標準ピッカーに長い文字列を流し込んでいるため、折り返しが発生して視認性が低い。タップして実機の挙動を確認できます。

  • 項目が長すぎて折り返し → 1 件あたりの占有面積が大きい
  • 背景が暗くコントラストが低い（iOS の仕様）
  • 絞り込み・検索ができない

案1: ラベル短縮（ネイティブのまま）

UI は今の <select> のまま、ラベルから ID suffix を取り除き全角スラッシュを半角スペースに置換。実装 5 分程度で 1 行に収まる確率が大幅に上がる。

  • 実装最小（select の option 文字列を変えるだけ、5分）
  • ID 値は value にだけ残せるので、サーバ送信は今のまま
  • ネイティブピッカーの暗い背景は変えられない（iOS 仕様）
  • 検索・絞り込みは依然できない

案2: カスタムドロップダウン

自前 UI に置換。日付・担当者・カテゴリ・進捗を構造化表示。検索ボックスも内蔵。タップして体験できます。

  • 視認性最良 — 列で揃うので走査しやすい
  • 検索ボックスで担当者/カテゴリ即フィルタ
  • 選択中のチェックマーク・進捗 100% の色分けも自由
  • 実装 1〜2 時間（CSS + 開閉/外側クリック判定/キーボード対応）

案3: 全画面モーダルピッカー

タップで全画面モーダル。検索 + カテゴリチップ絞り込み + 大きな日付表示。仕入れ件数が多い場合の最良解。

  • 仕入れ件数が増えても破綻しない（縦に長い領域が確保できる）
  • カテゴリチップで一気に絞り込める
  • 日付が大きくスキャンしやすい・進捗バーで視覚化
  • 実装 2〜3 時間（モーダルのみ最大、検索＋絞り込みも込み）
  • ワンタップ多くなる感が出る（モーダルで全画面占有）
