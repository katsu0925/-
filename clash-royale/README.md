# ロイヤルアリーナ（クラロワ風 1対1バトル）

個人利用向けのミニゲーム。ブラウザだけで動きます（インストール不要）。

## 遊びかた

`clash-royale/index.html` をダブルクリックしてブラウザで開くだけ。

1. 下のカードをタップ（クリック）して選ぶ
2. 青く光った自分の陣地をタップすると味方が出てくる
3. 相手のタワーを壊すとクラウン獲得。3分でクラウンが多いほうが勝ち
4. 同点なら延長戦（サドンデス）— 先にタワーを壊したほうが勝ち

- エリクサー（紫のバー）は時間で貯まり、最大10。残り1分からは倍速
- キングタワーを壊すと即勝利
- 相手のサブタワーを壊すと、その側の敵陣にも味方を出せるようになる

## カード

| カード | コスト | 特徴 |
|---|---|---|
| 👺 ゴブリン | 2 | 3体。足が速く火力が高いが紙耐久 |
| 🛡️ ナイト | 3 | 万能な壁役 |
| 🏹 アーチャー | 3 | 2体。遠距離、空も撃てる |
| 🦇 ミニオン | 3 | 3体。飛行。地上の的には無敵 |
| ☄️ アロー | 3 | 呪文。広範囲に小ダメージ（小型の群れ処理） |
| 🔫 マスケット | 4 | 長射程の主砲 |
| 🔥 ファイボ | 4 | 呪文。狭い範囲に大ダメージ |
| 🗿 ジャイアント | 5 | 高HP。タワーだけを殴りに行く攻めの軸 |

呪文（アロー・ファイボ）は盤面のどこにでも撃てます。タワーへのダメージは 35% に減衰。

## 中身

`index.html` の1ファイル完結（HTML + CSS + JavaScript、外部ライブラリなし）。
描画は Canvas、ロジックは `update()` / `draw()` の毎フレームループ。
カードの強さは `CARDS` オブジェクトの数値を書き換えるだけで調整できます。
